## Building and running locally

Pages are generated. Edit the generator scripts, never the `.html` output:

- `pages_*.py` write the English pages at the site root.
- `ms_pages_*.py` write the Bahasa Malaysia pages into `ms/`.
- `build.py` holds the shared head, header, menu and footer, the UI strings
  for both languages, and site settings (`SITE_URL`, `FORM_ACCESS_KEY`, ...).
  Running `python build.py` writes `sitemap.xml` and `robots.txt`.

Regenerate everything after a change (Windows: use the full Python path if
plain `python` opens the Microsoft Store):

```bash
python build.py
for f in pages_*.py ms_pages_*.py; do python "$f"; done
```

Then serve the folder with any static server and open it in a browser:

```bash
python -m http.server 8080
```

Every content change must be made in both the English and the BM generator.

## Contact form

The form in `contact.html` validates client-side and delivers messages through
[Web3Forms](https://web3forms.com):

1. Create a free access key at web3forms.com using the inbox that should
   receive enquiries (for example info@klseri.com.my).
2. Paste it into `FORM_ACCESS_KEY` in `build.py`.
3. Re-run `pages_contact.py` and `ms_pages_contact.py`.

Until a key is set, pressing "Send message" opens the visitor's email app with
the message already addressed to `FORM_FALLBACK_EMAIL`, so no enquiry is lost.
A hidden honeypot field filters simple spam bots.

## Design notes (v4)

- **Colour:** brand green `#009447` for actions and links, deep green
  `#00381D` for dark sections, amber `#E3A73B` only as an indicator-lamp
  accent. Light theme only.
- **Type:** Archivo (variable width, set at 106-112%) for headings, IBM Plex
  Sans for text. Sentence case everywhere, no all-caps labels.
- **Shape:** 3-6px radii, solid surfaces, no glass or blur, no colour washes
  over photos.
- **Motion:** only the home intro, the pinned industries showcase, photo
  reveals, count-ups and page transitions. Everything respects
  `prefers-reduced-motion`.
